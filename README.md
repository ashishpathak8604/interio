# 🏡 Interio Park — Luxury Interior Design Experience

**Spaces That Tell Your Story.**

A cinematic, premium digital experience designed for Interio Park, a luxury interior design studio. The website showcases thoughtfully curated interior collections through immersive photography, elegant typography, smooth scrolling and cinematic page transitions.

🌐 **Live Website:**  https://interio-liv.vercel.app/

---

## ✨ About the Project

Interio Park is a luxury interior design website created to present the studio's design philosophy, craftsmanship and portfolio through an elegant digital experience.

The goal was to move beyond a conventional business website and create an immersive architectural gallery where visitors can explore interior collections, discover design inspiration and connect with the studio.

The design focuses on minimalism, premium aesthetics, immersive imagery and smooth interactions.

## 🚀 Key Features

- 🎬 **Cinematic Homepage:** Full-screen sections featuring immersive interior photography.
- 🏛️ **Dream Collection:** A curated gallery showcasing beautiful interior spaces.
- ✨ **Signature Collection:** A dedicated collection highlighting distinctive interior designs.
- 🖼️ **Asymmetric Image Galleries:** Editorial-style layouts combining horizontal and vertical imagery.
- 🎭 **Cinematic Page Transitions:** Custom animated vertical-panel transitions between pages.
- 📜 **Scroll-Based Animations:** GSAP-powered image reveals and layered section transitions.
- 🧭 **Minimal Navigation:** Transparent navigation with dedicated Studio, Philosophy and Contact pages.
- 📱 **Responsive Design:** Optimised layouts for desktop, tablet and mobile devices.
- ⚡ **Smooth Scrolling:** Fluid scrolling experience for a more immersive browsing journey.

## 🎨 Design Philosophy

The visual direction is inspired by luxury architecture and editorial interior design.

Key design principles:

- Minimalist and elegant compositions.
- Warm, sophisticated colour palettes.
- Bold and expressive typography.
- Large-scale architectural photography.
- Smooth, cinematic transitions.
- Clean layouts that let the interiors speak for themselves.

## 📂 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd interio-park
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

### 6. Preview production build

```bash
npm run preview
```
